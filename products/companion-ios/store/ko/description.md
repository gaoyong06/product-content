## Promotional Text

## Description
Companion은 나나와 조용히 이야기할 수 있는 공간입니다. 중요한 일은 기억하고, 나머지는 그 순간에 남겨 둡니다.

앱을 열고 지금 떠오르는 말을 전해 보세요. 한 문장이면 충분합니다. 텍스트 대화는 언제든 이용할 수 있고, 음성 메시지는 7일 무료 체험 후 구독으로 이어집니다.

할 수 있는 일
• 부담 없이 텍스트 채팅
• 음성이 열리면 음성 메시지 보내기
• 대화에 사진 공유
• 기억할 것과 잊을 것 선택
• 채팅 검색 및 비우기

서두르지 않는 조용한 경험을 지향합니다.

구독은 Apple ID로 결제되며 설정 → Apple ID → 구독에서 관리할 수 있습니다. 앱에서 구매 복원도 가능합니다.

프라이버시가 중요합니다. 자세한 내용은 개인정보 처리방침을 확인해 주세요.
