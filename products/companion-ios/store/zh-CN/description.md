## Description
娜娜是一个安静的陪伴空间。她会记住重要的事，其余的留给当下。

打开 App，说你此刻想说的话。一句话就够。文字陪伴始终可用；语音消息可先完整体验 7 天，之后通过订阅继续。

你可以用它做什么
• 随时文字聊天，不催促
• 在语音开通后发送语音消息
• 在对话里分享图片
• 选择记住什么、忘掉什么
• 搜索或清空聊天记录，重新开始

产品默认安静：更少页面、更少打扰，让你按自己的节奏说话。

订阅通过 Apple ID 扣费，可在「设置 → Apple ID → 订阅」管理。也可在 App 内恢复购买。

隐私很重要。记忆由你决定留下什么。详见隐私政策。
