## Description
娜娜是一個安靜的陪伴空間。她會記住重要的事，其餘的留給當下。

打開 App，說你此刻想說的話。一句話就夠。文字陪伴始終可用；語音訊息可先完整體驗 7 天，之後透過訂閱繼續。

你可以用它做什麼
• 隨時文字聊天，不催促
• 在語音開通後傳送語音訊息
• 在對話裡分享圖片
• 選擇記住什麼、忘掉什麼
• 搜尋或清空聊天紀錄，重新開始

產品預設安靜：更少頁面、更少打擾，讓你照自己的節奏說話。

訂閱透過 Apple ID 扣款，可在「設定 → Apple ID → 訂閱」管理。也可在 App 內回復購買。

隱私很重要。記憶由你決定留下什麼。詳見隱私權政策。
