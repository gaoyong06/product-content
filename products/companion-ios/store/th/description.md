# หน้า App Store ของ Companion (ภาษาไทย)

## App Name
`Companion`

## Subtitle
`เพื่อนที่จำได้`

## Promotional Text
แชทข้อความใช้ฟรีตลอด ทดลองเสียง 7 วัน แล้วต่อด้วยการสมัครสมาชิก App Store

## Keywords
`แชท,เสียง,คุย,จำ,สงบ`

## Description
Companion คือพื้นที่สงบสำหรับคุยกับ Nana — เพื่อนที่จำสิ่งสำคัญและปล่อยที่เหลือไว้กับช่วงเวลานั้น

เปิดแอปแล้วบอกสิ่งที่คิด ประโยคเดียวก็พอ ข้อความใช้ได้เสมอ ข้อความเสียงปลดล็อกช่วงทดลอง 7 วัน แล้วต่อด้วยการสมัครสมาชิก

คุณทำอะไรได้บ้าง
• แชทข้อความโดยไม่เร่งเร้า
• ส่งข้อความเสียงเมื่อปลดล็อกแล้ว
• แชร์รูปในบทสนทนา
• เลือกว่าจะจำหรือลืมอะไร
• ค้นหาหรือล้างประวัติแชท

ออกแบบให้รู้สึกสงบ

การสมัครสมาชิกเรียกเก็บผ่าน Apple ID จัดการได้ในตั้งค่า กู้คืนการซื้อในแอปได้

ความเป็นส่วนตัวสำคัญ ดูนโยบายความเป็นส่วนตัว
