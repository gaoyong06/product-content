## Description
Companion est un endroit calme pour parler avec Nana — une compagne qui retient l’essentiel et laisse le reste à l’instant.

Ouvrez l’app et dites ce qui vous traverse. Une phrase suffit. Le texte reste disponible. Les messages vocaux s’ouvrent pendant 7 jours d’essai, puis via abonnement.

Ce que vous pouvez faire
• Discuter par texte sans pression
• Envoyer des messages vocaux quand la voix est débloquée
• Partager des photos dans la conversation
• Choisir quoi mémoriser ou oublier
• Rechercher ou effacer l’historique

Une expérience posée, sans précipitation.

Les abonnements passent par l’identifiant Apple, gérables dans Réglages → Identifiant Apple → Abonnements. Restaurez vos achats dans l’app.

La vie privée compte. Voir la politique de confidentialité.
