# Companion App Store 掲載文（日本語）

## App Name
`Companion`

## Subtitle
`覚えていてくれる相棒`

## Promotional Text
テキストの会話は無料のまま。音声は7日間体験でき、その後はApp Storeのサブスクリプションで続けられます。

## Keywords
`チャット,相棒,音声,記憶,相談,対話,AI,日記,寄り添い,聞く`

## Description
Companionは、ナナと静かに話せる場所です。大切なことは覚え、それ以外はその瞬間に残します。

アプリを開いて、いま思うことを話してください。一文で十分です。テキストの会話はいつでも使えます。音声メッセージは7日間の無料体験のあと、サブスクリプションで続けられます。

できること
• いつでもテキストでチャット
• 音声が解放されたらボイスメッセージを送信
• 会話に写真を共有
• 覚えたいこと・忘れてほしいことを選べる
• チャット履歴の検索とクリア

落ち着いた体験を大切にしています。急かさず、静かにそばにいます。

サブスクリプションはApple ID経由で請求され、「設定 → Apple ID → サブスクリプション」で管理できます。アプリ内で購入を復元することもできます。

プライバシーを大切にします。詳しくはプライバシーポリシーをご覧ください。
