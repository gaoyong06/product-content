# HomepageTab

## Επισκόπηση

Μια καθαρή και προσαρμόσιμη νέα καρτέλα που κρατά τους αγαπημένους σας ιστότοπους, την αναζήτηση, τις σημειώσεις και τις καθημερινές πληροφορίες κοντά σας.

## Περιγραφή

Όταν ανοίγετε μια νέα καρτέλα, συνήθως θέλετε να κάνετε ένα πράγμα: να ανοίξετε έναν ιστότοπο, να βρείτε μια απάντηση ή να σημειώσετε μια ιδέα. Το HomepageTab συγκεντρώνει αυτές τις εισόδους σε μία γνώριμη σελίδα, ώστε να βρίσκετε γρηγορότερα το επόμενο βήμα και να αποσπάστε λιγότερο.

Τοποθετήστε τους ιστότοπους που χρησιμοποιείτε συχνά σε εύκολα προσβάσιμο σημείο. Προσθέστε όποτε χρειάζεται widget για ρολόι, καιρό, ημερολόγιο, αντίστροφη μέτρηση, σημειώσεις, εργασίες και παγκόσμια ώρα. Τακτοποιήστε τα widget και τη διάταξη όπως περιηγείστε ή κρατήστε μόνο όσα χρησιμοποιείτε πραγματικά.

Η αναζήτηση συνεχίζει να χρησιμοποιεί την τρέχουσα προεπιλεγμένη υπηρεσία αναζήτησης του προγράμματος περιήγησης και δεν αλλάζει τις ρυθμίσεις σας. Μετά τη σύνδεση μπορείτε να συγχρονίσετε τη διάταξη και τις συνηθισμένες ρυθμίσεις σε υποστηριζόμενες συσκευές· οι τοπικές λειτουργίες είναι διαθέσιμες και χωρίς λογαριασμό.

## Τι μπορείτε να κάνετε

- Να έχετε τους αγαπημένους ιστότοπους και τους αποθηκευμένους συνδέσμους πρόχειρους.
- Να βλέπετε ώρα, καιρό, ημερολόγιο, αντίστροφες μετρήσεις και παγκόσμια ώρα.
- Να γράφετε σημειώσεις και εργασίες χωρίς αλλαγή σελίδας.
- Να οργανώνετε widget, διάταξη και ταπετσαρία σύμφωνα με τις συνήθειές σας.

Το HomepageTab αντικαθιστά μόνο τη σελίδα νέας καρτέλας και δεν αλλάζει την προεπιλεγμένη υπηρεσία αναζήτησης.
