# HomepageTab

## Descripció breu

Una pàgina de pestanya nova neta i personalitzable, pensada per tenir a mà els teus llocs preferits, la cerca, les notes i la informació diària.

## Descripció

Quan obres una pestanya nova, normalment vols fer una sola cosa: obrir un lloc web, buscar una resposta o apuntar una idea. HomepageTab reuneix aquests accessos en una pàgina coneguda perquè trobis el pas següent amb menys distraccions.

Col·loca els llocs que uses sovint allà on siguin fàcils d'assolir. Afegeix ginys per al rellotge, el temps, el calendari, el compte enrere, les notes, les tasques i l'hora mundial quan els necessitis. Ordena els ginys i el disseny segons la teva manera de navegar, o conserva només allò que realment fas servir.

La cerca continua utilitzant el servei de cerca predeterminat del navegador i no en modifica la configuració. Després d'iniciar sessió pots sincronitzar el disseny i les opcions habituals entre dispositius compatibles, o utilitzar les funcions locals sense compte.

## Què hi pots fer

- Tenir els llocs preferits i els enllaços desats sempre a mà.
- Consultar l'hora, el temps, el calendari, el compte enrere i l'hora mundial.
- Escriure notes i tasques sense anar canviant de pàgina.
- Organitzar ginys, disseny i fons segons els teus hàbits.

HomepageTab només substitueix la pàgina de pestanya nova i no canvia el servei de cerca predeterminat.
