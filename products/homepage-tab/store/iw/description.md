# HomepageTab

## סקירה

כרטיסייה חדשה נקייה וניתנת להתאמה אישית, שמרכזת את האתרים המועדפים, החיפוש, ההערות והמידע היומי שלך במקום אחד.

## תיאור

כשפותחים כרטיסייה חדשה, בדרך כלל רוצים לעשות דבר אחד: לפתוח אתר, למצוא תשובה או לכתוב רעיון. HomepageTab מרכז את נקודות הכניסה האלה בדף מוכר, כך שקל יותר למצוא את הצעד הבא ויש פחות הסחות דעת.

מקמו את האתרים שבהם אתם משתמשים לעיתים קרובות במקום נגיש. הוסיפו לפי הצורך ווידג'טים לשעון, למזג האוויר, ללוח שנה, לספירה לאחור, להערות, למשימות ולשעון עולמי. סדרו את הווידג'טים ואת פריסת הדף לפי אופן הגלישה שלכם, או השאירו רק את מה שבאמת בשימוש.

החיפוש ממשיך להשתמש בשירות החיפוש המוגדר כברירת מחדל בדפדפן ואינו משנה את ההגדרות שלכם. לאחר התחברות אפשר לסנכרן את הפריסה וההגדרות הרגילות בין מכשירים נתמכים; תכונות מקומיות זמינות גם ללא חשבון.

## מה אפשר לעשות

- לשמור את האתרים המועדפים והקישורים השמורים בהישג יד.
- לראות שעה, מזג אוויר, לוח שנה, ספירות לאחור ושעה עולמית.
- לכתוב הערות ומשימות בלי לעבור בין דפים.
- לסדר ווידג'טים, פריסה וטפט לפי ההרגלים שלך.

HomepageTab מחליף רק את דף הכרטיסייה החדשה ואינו משנה את שירות החיפוש המוגדר כברירת מחדל.
