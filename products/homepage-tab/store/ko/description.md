# HomepageTab

## 개요

자주 찾는 웹사이트, 검색, 메모와 일상 정보를 한곳에 두는 깔끔하고 맞춤 설정 가능한 새 탭입니다.

## 설명

새 탭을 열 때 보통 원하는 일은 하나입니다. 사이트를 열거나, 답을 찾거나, 아이디어를 적는 일이죠. HomepageTab은 이런 시작점을 익숙한 한 페이지에 모아 다음에 할 일을 더 빨리 찾도록 도와줍니다.

자주 사용하는 사이트를 손이 닿기 쉬운 곳에 배치하고, 필요할 때 시계, 날씨, 캘린더, 카운트다운, 메모, 할 일과 세계 시계 위젯을 추가하세요. 브라우징 방식에 맞춰 위젯과 페이지 구성을 정리하거나 실제로 사용하는 것만 남길 수 있습니다.

검색은 계속 브라우저의 현재 기본 검색 서비스를 사용하며 검색 설정을 바꾸지 않습니다. 로그인하면 지원되는 기기 사이에서 레이아웃과 기본 설정을 동기화할 수 있고, 계정 없이도 로컬 기능을 사용할 수 있습니다.

## 할 수 있는 일

- 즐겨 찾는 사이트와 저장한 링크를 쉽게 찾기.
- 시간, 날씨, 캘린더, 카운트다운과 세계 시계 확인하기.
- 페이지를 오가지 않고 메모와 할 일 작성하기.
- 위젯, 레이아웃과 배경화면을 내 방식에 맞게 정리하기.

HomepageTab은 새 탭 페이지만 바꾸며 브라우저의 기본 검색 서비스는 변경하지 않습니다.
