# HomepageTab Chrome Web Store 详情页文案

## 概述

一个清爽、可以按自己习惯整理的新标签页。常用网站、搜索、笔记和日常信息，打开就能看到。

## 详情描述

打开新标签页，通常只想做一件事：找到一个网站、查一个问题，或者记下一件事。HomepageTab 把这些入口放在同一个页面里，让下一步更容易找到，也让页面保持足够安静。

常用网站和收藏入口可以放在顺手的位置。时钟、天气、日历、倒数日、笔记、待办和世界时间等内容，按需要添加即可；小组件的位置和页面布局也可以自由调整。只留下真正会用到的内容，首页就不会被无关信息占满。

搜索仍然使用浏览器当前的默认搜索服务，不改变你的搜索习惯。需要时，可以在页面中切换其他搜索引擎或 AI 助手。壁纸和明亮、深色页面外观，则让这个每天都会打开的页面更符合你的偏好。

登录后，可以在支持的设备间同步桌面布局和常用设置；不登录时，网页版和浏览器扩展也可以继续使用本地功能。

HomepageTab 适合希望新标签页简单、顺手，又希望常用内容触手可及的人。安装后打开新标签页，即可开始使用。

## 你可以用它做什么

- 把常用网站和收藏入口放在容易找到的位置。
- 用小组件查看时间、天气、日历、倒数日和世界时间。
- 随手记下笔记和待办，避免在不同页面之间来回切换。
- 按自己的习惯调整小组件位置、页面布局和壁纸。
- 使用浏览器默认搜索，也可以切换已提供的搜索引擎和 AI 助手。
- 登录后同步桌面布局和常用设置，也可以不登录使用本地功能。
